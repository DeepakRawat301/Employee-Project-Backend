It is a backend Spring Boot Project of Employee where ( CRUD )  Create, Read, Update and Delete operations are performed in Employee Record and MySql database is used to store records. And the FrontEnd part you can access on Front end repository which is made in React JS. 
You can run this project on your system.
Open it on any IDE preffered Intellij Idea.
Make suitable changes is Application properties file your DBMS (username, password and all other).
Then run main application file and it will run on your local server port local host 8080.
Make sure the port 8080 is free and no other application is running is same port.
If you want to change the port then make change in application properties.
Run main file.
